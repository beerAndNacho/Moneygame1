# Moneygame1 Pixel Art V7 Art Direction

## 목적
기존 게임의 기능을 유지하면서 화면을 `레트로 2D 픽셀 게임`으로 통일한다. 외부 에셋을 그대로 복제하지 않고, itch.io의 무료 픽셀 에셋 생태계, Lospec의 제한 팔레트, Kenney의 모듈형 구성, Piskel의 스프라이트 애니메이션 작업 방식을 **레퍼런스**로 삼는다.

## 핵심 원칙
- 16px 또는 24px 기준 그리드
- nearest-neighbor 렌더링으로 픽셀 경계 보존
- 해역마다 1개 대표 팔레트 + 보조색 2~4개
- 캐릭터/배/물고기는 검은 외곽선보다 진한 해역색을 사용해 가독성 확보
- 물고기는 배경보다 높은 명도 대비를 확보하고 최소 2~3프레임의 꼬리/지느러미 애니메이션 적용
- HUD는 반투명 유리 UI가 아니라 레트로 패널/픽셀 테두리 사용

## 화면별 아트
### 항구
- 나무 부두, 상점 간판, 어시장 좌판, 선박소, 창고
- NPC는 16~24px 캐릭터로 통일
- 판매/구매 버튼은 물고기 아이콘 + 가격 + 등급으로 즉시 판단

### 해상
- 하늘/수평선/파도/부표/갈매기/배 그림자를 다층 패럴랙스로 구성
- 해역마다 파도 패턴과 배경 오브젝트를 변경
- 조업 중인 통발 위치를 부표와 라인으로 명확히 표시

### 수중
- 화면을 수심별 3층으로 나눔
- 전경 어종은 크게, 중경은 보통, 후경은 작게 렌더링
- 목표 어종에는 짧은 반짝임/링 효과와 이름표를 사용
- 어군은 정지하지 않고 좌우/상하 속도를 다르게 적용

## 16개 해역 비주얼 방향
1. 초보 연안 — 맑은 청록, 작은 멸치/전갱이
2. 방파제 — 콘크리트/부표, 고등어/우럭
3. 갯바위 — 해조류/성게, 볼락/문어
4. 모래톱 — 모래 소용돌이, 광어/가자미
5. 다시마숲 — 짙은 녹청, 전복/쥐치
6. 난파선 — 녹슨 선체, 농어/쏨뱅이
7. 야간항로 — 남색/보라, 갈치/오징어
8. 한류수역 — 차가운 청색, 대구/명태
9. 난류수역 — 따뜻한 청록, 참돔/방어
10. 산호초 — 제한된 선명 팔레트, 열대어
11. 심해협곡 — 남보라/검정, 아귀/심해어
12. 해저동굴 — 암석 대비, 장어/갑오징어
13. 폭풍해역 — 회색 바다, 청상아리 등 희귀 이벤트
14. 화산해역 — 적갈색 광원, 용암 주변 특수어종
15. 극한심해 — 최소 팔레트, 초희귀 어종
16. 전설의 어장 — 황금 포인트, 전설 어종 출현

## 에셋 사용 정책
외부 무료 에셋을 실제 프로젝트에 넣을 때는 **개별 에셋의 라이선스를 각각 확인**한다. Kenney의 게임 에셋은 CC0로 상업 프로젝트 사용이 가능하다고 명시되어 있지만, 다른 사이트의 '무료' 표시는 동일한 라이선스를 의미하지 않는다.

## V7 재미 개선 우선순위
1. 물고기가 실제로 보이는가
2. 물고기를 발견/잡는 순간 피드백이 강한가
3. 잡은 물고기를 어디에 팔지 고민하게 만드는가
4. 배 업그레이드가 새로운 플레이를 여는가
5. 다음 해역을 해금하고 싶게 만드는가
6. 시장 이벤트가 매번 다른 선택을 만들고 있는가
