# 파도 아래: 트랩라인 — Moneygame1 V2

모바일 세로 화면에 최적화된 통발 낚시·수집·경제 시뮬레이션 웹게임입니다. 1차 MVP의 즉시 출항형 플레이를 **통발 설치 → 대기 → 회수 → 다중 어획 → 판매·납품 → 선박 성장** 구조로 확장했습니다.

## 실행

별도 API 키나 데이터베이스가 필요하지 않습니다.

```bash
npm run start
```

브라우저에서 `http://localhost:4180`으로 접속합니다.

## 테스트

```bash
npm run check
npm test
```

현재 자동 테스트는 콘텐츠 수량, 설치 판정, 오프라인 타이머, 결정적 어획, 다중 어획, 부분 성공, 신선도, 변동 시세, 일일 의뢰, 저장 마이그레이션, 전체 경제 루프 등을 검증합니다.

## V2 핵심 기능

- 5개 해역, 36종 생물, 5종 통발, 8종 미끼
- 목표 지점에 통발을 놓는 설치 미니게임
- 최대 3개의 통발을 동시에 운용하는 트랩라인
- 브라우저를 닫아도 실제 시간이 반영되는 대기 타이머
- 해저 이탈·중층 회수·수면 돌파 3단계 회수 미니게임
- 장력·잠금·내구도·위험 이벤트·PERFECT 콤보
- 실패 시 전부 잃지 않는 부분 회수
- 한 통발에서 여러 생물이 나오는 다중 어획
- 크기 등급, 신선도, 개인 기록, 도감
- 섬마을 직거래와 변동형 도시 수산시장
- 전동 윈치, 통발 거치대, 어군 탐지기, 냉장고, 선체, 엔진 성장
- 일일 의뢰와 메인 스토리 챕터
- 기존 V1 저장 데이터를 V2로 자동 이관
- PWA 설치, 오프라인 캐시, 진동, 브라우저 알림

## 플레이 흐름

1. 항구에서 해역·통발·미끼를 고릅니다.
2. 설치 미니게임으로 통발의 설치 품질을 결정합니다.
3. 트랩라인에서 여러 통발의 진행 시간을 관리합니다.
4. 준비된 통발을 타이밍 조작으로 회수합니다.
5. 어획물을 보관하거나 두 시장의 가격을 비교해 판매합니다.
6. 수익으로 배를 업그레이드하고 더 깊은 해역을 개방합니다.

## 기술 구조

- 의존성 없는 ES Module JavaScript
- Canvas 2D 해상·미니게임 렌더링
- 반응형 CSS 모바일 UI
- `localStorage` 기반 버전형 저장 데이터
- Node 내장 테스트 러너
- Service Worker와 Web App Manifest
- Vercel 정적 배포

## 주요 파일

```text
.
├── index.html
├── src/styles/*.part    # 조립되는 반응형 CSS 원본
├── src/game/*.part      # UI, 화면 전환, 미니게임 원본
├── src/core/*.part      # 데이터, 계산 함수, 저장소·경제 원본
├── scripts/build.mjs    # 원본 파트를 실행 가능한 정적 파일로 조립
├── service-worker.js
├── manifest.webmanifest
├── assets/
├── tests/core.test.js
└── docs/V2_IMPLEMENTATION.md
```

## 저장 데이터

V2 저장 키는 `moneygame1-trapline-v2`입니다. 기존 `trap-night-save-v1`, `moneygame1-save-v1` 데이터가 발견되면 가능한 진행도를 유지한 채 자동 변환합니다.

## 현재 범위

V2는 싱글 플레이 PWA입니다. 계정 로그인, 클라우드 동기화, 네이티브 예약 푸시, 광고·인앱 결제는 다음 단계 범위로 분리되어 있습니다.
