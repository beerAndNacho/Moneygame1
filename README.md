# 파도 아래: 통발 일지

세로형 모바일 화면에서 통발을 원하는 수심까지 내리고, 타이밍 구간에 맞춰 끌어올리는 낚시·수집 게임 프로토타입입니다. 참고 영상의 핵심 재미인 **투하 → 대기 → 회수 타이밍 → 포획 → 판매·강화·도감** 루프를 독자적인 세계관과 코드 기반 그래픽으로 구현했습니다.

## 실행

별도 패키지 설치가 필요하지 않습니다.

```bash
npm run serve
```

브라우저에서 `http://localhost:4173`을 엽니다. 모바일 화면 또는 개발자 도구의 모바일 뷰에서 플레이하는 것을 권장합니다.

## 테스트

```bash
npm run check
```

## 구현 기능

- 길게 눌러 통발 수심 결정
- 움직이는 타이밍 바 기반 회수 미니게임
- PERFECT / GOOD / MISS, 콤보, 줄 장력, 포획 안정도
- 거센 물살과 큰 그림자 위험 이벤트
- 낚시터 3곳과 레벨 해금
- 미끼 3종, 장비 3종, 장비 5단계 강화
- 바다 생물 16종과 희귀도 5단계
- 길이·무게·판매가 랜덤 기록
- 어시장 개별·일괄 판매
- 해양 도감과 최고 기록
- 일일 마을 의뢰와 보상
- 체력·시간·날씨·경험치·레벨
- `localStorage` 자동 저장
- 효과음, 진동 피드백, PWA 설치·오프라인 캐시
- 외부 이미지나 유료 API가 필요 없는 순수 HTML/CSS/JavaScript 구성

## 조작

1. 항구에서 낚시터와 미끼를 고릅니다.
2. `통발을 놓으러 가기`를 누릅니다.
3. 조업 화면의 큰 버튼을 길게 눌러 통발을 내립니다.
4. 원하는 수심에서 손을 떼고 미끼가 퍼질 때까지 기다립니다.
5. 빛나는 타이밍 구간에 커서가 들어왔을 때 `당기기`를 누릅니다.
6. 물살 경고가 나오면 잠시 기다립니다.
7. 통발을 수면까지 회수한 뒤 어시장 판매, 장비 강화, 도감 확인을 진행합니다.

## 구조

```text
.
├── index.html            # 화면 구조와 접근성 마크업
├── styles.css            # 모바일 UI, 픽셀 아트형 CSS 그래픽
├── game.js               # 화면 전환, 저장, 캔버스 렌더링, 게임 루프
├── game-core.js          # 생물 데이터와 순수 게임 계산 함수
├── tests/                # Node 내장 테스트 러너 기반 단위 테스트
├── service-worker.js     # 오프라인 캐시
├── manifest.webmanifest  # PWA 설정
├── assets/icon.svg       # 앱 아이콘
└── vercel.json           # 정적 배포·보안 헤더 설정
```

참고 영상의 장르와 상호작용 구조만 분석했으며, 게임명·세계관·UI·그래픽·생물 아이콘·문구는 독자적으로 구성했습니다. 상용화 시에도 원본 작품의 명칭, 캐릭터, 스프라이트, 사운드, 대사, 화면을 그대로 복제하지 않는 방향을 유지해야 합니다.
